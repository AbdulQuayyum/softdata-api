# Code of Conduct

## Our Commitment

SoftData is committed to providing a welcoming, respectful and inclusive environment for everyone participating in the project.

## Expected Behaviour

Participants should:

- Communicate respectfully.
- Provide constructive feedback.
- Accept reasonable disagreement.
- Focus criticism on ideas and contributions.
- Respect contributors’ time and experience.
- Correct mistakes openly.
- Credit the work and sources of others.
- Protect private and sensitive information.

## Unacceptable Behaviour

The following behaviour is unacceptable:

- Harassment or intimidation
- Discrimination
- Personal attacks
- Threats
- Deliberate disruption
- Publishing another person’s private information
- Submitting stolen, confidential or illegally obtained data
- Repeatedly ignoring maintainer instructions
- Misrepresenting generated or unofficial data as authoritative

## Dataset Discussions

Disagreements about data should be resolved using evidence.

Contributors should provide:

- Reliable sources
- Publication dates
- Licence information
- Clear explanations

Nationality, identity, political opinion or personal preference should not be treated as evidence of data accuracy.

## Enforcement

Maintainers may:

- Edit or remove inappropriate content
- Close discussions
- Reject contributions
- Issue warnings
- Temporarily restrict participation
- Permanently remove participants in serious cases

Enforcement decisions should be proportionate and documented where appropriate.
